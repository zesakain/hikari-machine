- **Milestone 8B.5: External 3D Asset Import Pipeline**:
  - **glTF 2.0 & GLB Import Pipeline**:
    - Vendored `cgltf` (v1.14 pinned, MIT license, single header) with zero external runtime dependencies and full C++20 `-fno-exceptions` / `-fno-rtti` compatibility.
    - Implemented `render::GltfImporter` (`engine/render/include/render/gltf_importer.h`, `engine/render/src/gltf_importer.cpp`) supporting both binary `.glb` containers and `.gltf` JSON descriptors with external `.bin` files and inline base64 data URIs.
    - Preserved full backward compatibility with Wavefront OBJ models via `ObjImporter`.
  - **Geometry, Node Transforms & Coordinate System Handling**:
    - Extracted vertex positions, normals, texture coordinates (UVs), vertex colors, and indices into engine `MeshData` and `Submesh` structures.
    - Maintained native right-handed $+Y$ up coordinates with $-Z$ view orientation without requiring axis permutations.
    - Evaluated full node hierarchy world transforms via `cgltf_node_transform_world()`, baking node positions, orientations, and scales directly into model vertex positions.
    - Transformed normals using the inverse-transpose of the upper $3\times3$ world matrix ($M^{-T}$) to guarantee normal perpendicularity under non-uniform scale.
    - Detected negative scaling (reflection / mirroring via $\det(M_{3\times3}) < 0$) and reversed triangle index winding order to maintain counter-clockwise front faces and correct back-face culling.
    - Implemented automatic normal generation fallback (`MeshData::generateNormals()`) for geometry omitting normal attributes, and defaulted missing texture coordinates to $(0, 0)$.
    - Generated synthetic sequential index buffers for non-indexed primitives and recalculated model bounding boxes (`AABB`).
  - **glTF 2.0 PBR Metallic-Roughness Materials**:
    - Expanded engine `Material` representation (`engine/render/include/render/material.h`) with base color factor, metallic factor, roughness factor, emissive factor, alpha mode (`Opaque`, `Mask`, `Blend`), and alpha cutoff.
    - Added `TextureInfo` and `TextureSamplerDesc` capturing texture file paths, coordinate set indices, address modes, filter modes, and color spaces (`Linear` vs `sRGB`).
    - Added `materialIndex` tracking to `Submesh` and material collections with query methods to `MeshData`.
  - **AssetManager Caching & Transactional Safety**:
    - Integrated format routing in `AssetManager::loadMesh()` by file extension (`.gltf`, `.glb`, `.obj`).
    - Implemented deterministic asset hashing (`AssetId::fromString(filepath)`), CPU mesh caching, and GPU mesh upload deduplication.
    - Maintained atomic failure handling: corrupt files or missing buffers leave no dangling entries or partial data in the asset registry.

### Fixed
- **Script Component Enable Toggle and Routine Configuration in Editor**:
  - Fixed an issue where the Script Component's **Enable** toggle could not be activated or immediately reverted to unchecked after adding the component in the Inspector.
  - **Root Cause**: When adding a `ScriptComponent`, `scriptName` was hardcoded to `"scripts/main.lua"`, which was not a registered global Lua function. On the very next simulation step in `world.progress()`, `ScriptUpdateSystem` failed to find the function, invoked error isolation, and set `comp.enabled = false`. Furthermore, `scriptName` was rendered as read-only text in the Inspector, preventing the user from correcting the routine name or keeping it unassigned.
  - **Remedy**:
    - Initialized new `ScriptComponent` instances with an empty routine name (`scriptName = ""`) and `enabled = true`. Unassigned script components cleanly bypass invocation without error or auto-disabling.
    - Added an editable `InputTextWithHint` field in `InspectorPanel` so users can configure, inspect, and update the Lua routine name.
    - Connected enabled checkbox toggling and routine edits to Flecs `e.modified<ScriptComponent>()` notifications.
    - Added real-time visual status badges: `[Active]`, `[Unassigned]`, and `[Disabled]`.
    - Added `Script Component` to the `WorkspaceManager` main `Component` menu.
    - Registered a default global `on_update(entity, dt)` hook in `src/main.cpp`.
    - Added comprehensive regression tests in `tests/unit/editor/editor_test.cpp` (`testScriptComponentEnableToggleBehavior`) and `tests/unit/script/script_test.cpp` (`testScriptEnableLifecycle`).
- **Physics Object & Entity Creation Crash in Scene Hierarchy**:
  - Fixed fatal assertion `flecs.c: 9695: assert: entity != 0 INVALID_PARAMETER` triggered when adding Physics Objects, Empty Entities, or duplicated entities in the Scene Hierarchy.
  - **Root Cause**: `generateUniqueEntityName` polled candidate names using `while (ecs.lookup(candidate).is_alive())`. When an entity name did not yet exist, Flecs returned an entity handle with ID `0`. Invoking `.is_alive()` on entity ID `0` asserted in `ecs_is_alive()`.
  - **Remedy**: Refactored `HierarchyPanel::generateUniqueEntityName` to inspect `existing.id() == 0 || !existing.is_valid()` before checking liveness, enabling safe and clean loop termination.
  - Hardened entity rendering queries and inspection panels against stale/invalid handles (`isAlive()` and `is_valid()` checks).
  - Promoted `hierarchy_panel.h` to public editor include `editor/hierarchy_panel.h` and unified GameObject menu creation to use collision-free unique name generation.
  - Added regression test suite (`testInvalidEntityLookupSafety`, `testPhysicsObjectCreationAndUniqueNamingRegression`, `testRepeatedPhysicsObjectCreationAndHierarchyRendering`) in `tests/unit/editor/editor_test.cpp`.

    - Explicit state transitions with validation: `Edit -> Playing`, `Playing -> Paused`, `Paused -> Playing`, `Playing -> Stopped`, `Paused -> Stopped`, `Stopped -> Playing`.

    - Built an in-memory staging mechanism using `SceneSerializer` to clone the authoring `EditWorld` into an ephemeral `RuntimeWorld` without disk I/O.

    - Pristine reset: on `stop()`, `RuntimeWorld`, Jolt physics bodies, and Lua state are completely destroyed, and the editor seamlessly returns to Edit Mode with the `EditWorld` identical to its pre-Play state.
  - **Simulation Systems & Jolt Physics Lifecycle**:
    - Automated binding and instantiation of Jolt rigid bodies for deserialized `RigidBodyComponent` and `ColliderComponent` archetypes upon Play.
    - Continuous transform synchronization via `PhysicsPreSync`, `PhysicsStep`, and `PhysicsPostSync`.
    - Reverse-order teardown ordering ensuring Flecs `OnRemove` observers clean up physics bodies before `PhysicsWorld` is freed.
  - **Editor Toolbar & UI Integration**:
    - Upgraded transport simulation controls: state-gated Play, Pause, Resume, Step, and Stop buttons with contextual accent styling.
    - Dynamic simulation mode badges (`[EDIT MODE]`, `[PLAYING]`, `[PAUSED]`) in the toolbar and status bar.
