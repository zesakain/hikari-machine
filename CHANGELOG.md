## [Unreleased]

### Added
- **Jolt Physics Integration (Phase 5A)**:
  - Integration of Jolt Physics v5.6.0 via CMake `FetchContent` pinned without exceptions or RTTI.
  - Subsystem encapsulation in `engine/physics/` (`eng::physics`) with Jolt headers isolated strictly within private implementation files (`src/`).
  - Global `PhysicsSystem` lifecycle manager with idempotent initialization and teardown.
  - `PhysicsWorld` managing rigid bodies via `GenerationalHandle`-based `BodyHandle`.
  - Static, Kinematic, and Dynamic rigid body motion types with Box, Sphere, and Capsule geometric colliders.
  - Spatial intersection queries: `RaycastQuery` with surface normal evaluation and `ShapeCastQuery` (sphere sweep).
  - Fixed-timestep simulation accumulator ensuring frame-rate independence and avoiding simulation spirals.
  - Contact event collection with `CollisionEvent` reporting contact lifecycle events (Added, Persisted, Removed).
  - Flecs ECS integration: `RigidBodyComponent`, `ColliderComponent`, `PhysicsTransformComponent`, with continuous kinematic transform push, dynamic transform pull, and automatic body destruction via `OnRemove` observer.
- **Skeletal Animation System (Phase 5B)**:
  - Subsystem in `engine/anim/` (`eng::anim`) for skeletal hierarchy, animation sampling, and forward kinematics.
  - `Bone` hierarchy and `Skeleton` class maintaining topological sort DAG order for linear $O(N)$ forward kinematics pose evaluation and inverse bind matrix computation.
  - `AnimationClip` with multi-channel `BoneTrack` storing keyframes for translation, rotation, and scale.
  - `AnimationSampler` evaluating keyframe channels using linear interpolation (LERP) for translation and scale, and spherical linear interpolation (SLERP) with shortest-path hemisphere check for rotation.
  - `AnimationController` supporting playback control (play, pause, resume, stop), looping, playback speed scaling, and cross-fade blending between animation clips over arbitrary durations.
  - Flecs ECS integration: `SkeletonComponent`, `AnimationComponent`, and `SkinningPaletteComponent` evaluated within the `Continuous` system group.
- **Architecture Documentation (ADR-0012 & ADR-0013)**:
  - `ADR-0012`: Jolt Physics integration, fixed-timestep accumulator, Conductor continuous simulation gating, and Flecs ECS lifecycle sync.
  - `ADR-0013`: Skeletal animation system architecture, topological forward kinematics, SLERP interpolation, and cross-fade blending.
- **Testing & Quality Assurance (Phase 5)**:
  - Unit tests in `tests/unit/physics/physics_test.cpp` verifying physics lifecycle, body handles, gravity stepping, collision events, raycasts, shape sweeps, and ECS observers.
  - Unit tests in `tests/unit/anim/anim_test.cpp` verifying skeleton DAG validation, forward kinematics, rest-pose identity skinning, SLERP rotation, cross-fade blending, and ECS palette evaluation.

- **Vulkan RHI Backend & Dynamic Rendering (Phase 4.1)**:
  - Concrete hardware-accelerated Vulkan backend (`eng::rhi::vk::VulkanDevice`) in `engine/rhi/src/vulkan/` supporting Vulkan 1.3+ core capabilities.
  - Zero graphics API headers leaked outside `/engine/rhi` in compliance with Section 2 Rule 3.
  - Dynamic validation layer discovery (`VK_LAYER_KHRONOS_validation`) with graceful fallback when unavailable.
  - GPU capability scoring and enumeration mapping hardware to `GpuCaps` (Pascal GT 1030 Tier 0 test floor).
  - Explicit GPU memory management (`VulkanMemoryManager`) for device-local and host-visible/coherent allocations.
  - Generational resource tables for buffers, textures (2D, 3D, Cubemap), and samplers with stale handle protection.
  - Command list recording (`VulkanCommandList`) with synchronization2 barriers, dynamic rendering viewports/scissors, and CPU-to-GPU staging updates.
  - Presentation and swapchain management (`VulkanSwapchain`) integrated with SDL3 Vulkan surfaces.
- **Render Graph Architecture & Pass Scheduler (Phase 4.2)**:
  - Backend-independent DAG Render Graph (`eng::render::RenderGraph`) in `engine/render/include/render/render_graph.h`.
  - Pass declaration builder (`RenderPassBuilder`) for resource read/write dependency tracking with explicit access types.
  - Two-phase resource edge compilation with Kahn's topological sort and DFS cycle detection (`ErrorCode::RenderGraphCompilationFailed = 307`).
  - Transient resource lifetime analysis (`ResourceLifetime::overlaps`) for optimal memory alias planning.
  - State transition and barrier synchronization planning between passes.
  - Polymorphic pass executor dispatching recorded commands to `RhiCommandList`.
- **Architecture Documentation (ADR-0010 & ADR-0011)**:
  - `ADR-0010`: Vulkan 1.3+ RHI backend architecture, dynamic rendering, synchronization2, memory management, and SDL3 swapchain.
  - `ADR-0011`: Render graph DAG architecture, topological pass scheduling, cycle detection, and transient resource planning.
- **Testing & Quality Assurance (Phase 4.3)**:
  - Unit tests for render graph compilation, reverse pass ordering, diamond dependencies, cycle detection, and execution in `tests/unit/render/render_graph_test.cpp`.
  - Integration tests for physical Vulkan GPU detection, buffer/texture/sampler lifecycle, staging uploads, and queue submission in `tests/unit/rhi/vulkan_rhi_test.cpp`.

- **Shared World & Flecs ECS Integration (Phase 3.1)**:
  - Unified simulation `eng::world::World` in `<world/world.h>` wrapping Flecs ECS amalgamation v4.0.4 compiled as isolated C static library (`flecs_static`).
  - 64-bit generational `EntityHandle` in `<world/entity.h>` encapsulating entity ID and generation.
  - Component storage supporting POD components, mutable and const accessors (`setComponent`, `getComponent`, `getMutableComponent`, `hasComponent`, `removeComponent`), and zero-sized tag optimization (`addTag`).
  - System group phase gating (`SystemGroup::Continuous`, `StateA`, `StateB`) enabling and disabling entire system pipelines without tearing down systems or duplicating entities.
- **Two-State Conductor Execution Runtime (Phase 3.2)**:
  - Mode-based coordination runtime `eng::framework::Conductor` in `<framework/conductor.h>` coordinating two alternating execution states (Slot A and Slot B) over a single shared simulation World.
  - Abstract `Mode` interface in `<framework/mode.h>` defining lifecycle contracts (`enter`, `exit`, `update`, `prepare`, `commit`, `cancelPrepare`).
  - Decoupled clock domains: unscaled `WorldClock`, active gameplay `ActionClock` (scaled during transition entry), and unscaled `UiClock`.
  - Incremental budget-aware standby preparation (`prepare(world, budget)`) strictly adhering to per-frame microsecond budgets.
  - Atomic commit validation (`commit(world)`) verifying speculative caches before role reversal, with complete rollback safety on failure preserving the active state uninterrupted.
  - Smooth slow-motion transition curves scaling `ActionClock` without pausing physical simulation or UI systems.
- **Architecture Documentation (ADR-0008 & ADR-0009)**:
  - `ADR-0008`: Flecs ECS adoption, amalgamation vendoring in `engine/world/src/flecs/`, and third-party compiler warning isolation.
  - `ADR-0009`: Two-State Conductor execution runtime, shared world ownership, decoupled clocks, and atomic rollback semantics.
- **Headless Testing & Multi-Preset Verification (Phase 3.3)**:
  - Unit tests for World entity lifecycle, component access, and system group gating in `tests/unit/world/world_test.cpp`.
  - Unit tests for Conductor lifecycle, incremental preparation, commit validation, and rollback safety in `tests/unit/framework/conductor_test.cpp`.
  - Unit tests for independent clock scaling and slow-motion curves in `tests/unit/framework/clock_domain_test.cpp`.
  - Headless integration stress test executing 10,000 mode transitions with entity churn and flat memory verification in `tests/headless/conductor_stress_test.cpp`.

- **Platform Layer & SDL3 Backend (Phase 2.1)**:
  - Hardware-neutral window and event management encapsulated behind `eng::platform::Platform` and `Window` interfaces.
  - Zero SDL headers leaked into public engine headers; all SDL3 dependencies strictly isolated within `engine/platform/src/`.
  - Deterministic `InputSnapshot` capturing immutable keyboard (512 keys), mouse buttons (8), cursor pixel positions and deltas, and up to 4 gamepads.
  - Headless/offscreen dummy video driver fallback allowing full event pumping and window tests in CI without display servers.
  - Unit tests in `tests/unit/platform/platform_test.cpp` verifying snapshot immutability, delta detection, and window lifecycle.
- **RHI Layer & Null Mock Backend (Phase 2.2)**:
  - Graphics hardware abstraction behind `eng::rhi::RhiDevice` and `RhiCommandList` interfaces with zero graphics API leaks outside `/engine/rhi`.
  - Hardware tier classification and limits via `GpuCaps` (Tier 0 baseline for NVIDIA Pascal, AMD Polaris, Apple M1).
  - Generational resource handles (`BufferHandle`, `TextureHandle`, `SamplerHandle`, `PipelineHandle`, `ShaderHandle`) with stale-handle detection.
  - Resource descriptors (`BufferDesc`, `TextureDesc`, `SamplerDesc`) with parameter boundary checks against `GpuCaps`.
  - In-memory `NullDevice` and `NullCommandList` backend enabling headless execution, buffer updates, copies, and draw call recording without physical GPU drivers.
  - Unit tests in `tests/unit/rhi/null_rhi_test.cpp` covering caps queries, resource lifecycle, and command submission.
- **Architecture Documentation (ADR-0007)**:
  - Documented SDL3 adoption for windowing and input, isolation strategy, licensing compliance (zlib), and headless fallback.
- **Core Foundation Review & Stabilization (Phase 1.9)**:
  - Validated and audited Core modules across Phase 1.0–1.8 for memory safety, concurrency, API consistency, and portability.
  - Hardened `JobSystem` handle resolution to explicitly verify `JobState::Unallocated`, preventing fabricated unallocated handles from being accepted or waited on.
  - Added slot retirement at `kRetiredGeneration = 0xFFFF'FFFF` in `JobSystem::reclaim` and `reclaimCompletedSlotsLocked` to eliminate ABA generation wraparound hazards.
  - Added active dispatch assertion in `EventDispatcher::clear()` guarding reentrant clearing during iteration.
  - Added regression tests for unallocated handle rejection and generation overflow retirement in `job_system_test`.
- **Core Job System (Phase 1.8)**:
  - Bounded parallel scheduler `JobSystem` in `<core/job_system.h>` and `src/job_system.cpp` over caller-provided backing memory with zero heap allocations after initialization.
  - Generational job reference primitive `JobHandle` providing O(1) slot resolution with stale-handle detection.
  - Type-safe static callable abstraction (`JobFunction`, `VoidJobFunction`) with non-owning context pointer dispatch and zero `std::function` or virtual call overhead.
  - Directed acyclic graph (DAG) dependency tracking with inline fan-in/fan-out links, explicit cycle rejection (`addDependency`), and cascading failure propagation.
  - Deadlock-free `wait()` and `waitAll()` via cooperative work-helping on calling threads with 0 worker starvation.
  - Lifecycle management supporting configurable background workers (`initializeWorkers`), thread-safe idempotent shutdown (`shutdown`), and safe slot reclamation (`reclaim`).
  - Comprehensive unit test suite in `tests/unit/core/job_system_test.cpp` verified across all 6 presets including ThreadSanitizer.
- **Core Typed Event System (Phase 1.7)**:
  - Type-safe, RTTI-free event dispatching with unique compile-time generated `EventTypeId` (`StrongId<EventTypeTag, uint32_t>`) and `ListenerToken` (`StrongId<ListenerTag, uint64_t>`).
  - `EventDispatcher` in `<core/event.h>` and `src/event.cpp` supporting multiple listeners per event type over caller-provided storage with zero heap allocation.
  - Safe reentrancy semantics: listeners registered during active dispatch are deferred until subsequent dispatches; unregistration is deferred until outermost dispatch completion.
  - Type-erased function pointer and context dispatch supporting free functions, lambdas, and member functions without `std::function` or virtual inheritance.
  - `EventQueue<Event>` in `<core/event.h>` providing a bounded, circular ring buffer for deferred FIFO event processing over caller-provided memory.
  - Zero heap allocation on enqueue and drain paths, explicit capacity overflow rejection with dropped count tracking, and non-trivial payload lifecycle management.
  - Comprehensive unit test suite in `tests/unit/core/event_test.cpp`.
- **Core Strong IDs & Type Utilities (Phase 1.6)**:
  - `StrongId<Tag, Rep>` in `<core/id.h>` providing zero-overhead, compile-time differentiated identifiers over unsigned integer representations.
  - Invalid sentinel support (`kInvalidValue = 0`, `isValid()`, explicit `bool` operator, explicit conversions).
  - `IdGenerator<Id>` providing monotonic identifier generation with saturation detection and overflow protection without wraparound.
  - Compile-time type utilities (`kIsStrongId`, `StrongIdType`, `UnderlyingIdType`, `IdLike`).
  - Comprehensive unit test suite in `tests/unit/core/id_test.cpp`.
- **Core Slot Map (Phase 1.5)**:
  - `SlotMap<T>` in `<core/slot_map.h>` providing a stable-reference, generational object container indexed by `GenerationalHandle` over caller-provided backing memory.
  - Zero heap allocation and no dynamic resizing; explicit capacity bounds and safe failure modes.
  - O(1) in-place construction (`emplace`) and destruction (`erase`) supporting non-copyable and non-movable non-trivial types.
  - Generation tracking with safe overflow handling (`kRetiredGeneration`) preventing ABA stale-handle resurrection.
  - Comprehensive unit test suite in `tests/unit/core/slot_map_test.cpp`.
- **Core Structured Logging (Phase 1.4)**:
  - `LogLevel` enum and string conversion in `<core/log.h>` providing `Trace`, `Debug`, `Info`, `Warning`, `Error`, and `Critical` severity tiers.
  - `LogRecord` structured record layout capturing monotonic timestamp, severity, category tag, source location, and fixed-capacity message payload.
  - `Logger` in `<core/log.h>` and `src/log.cpp` implementing a non-blocking, bounded ring buffer with configurable severity filtering, zero hot-path heap allocation, non-blocking overflow rejection, and dropped record accounting.
  - `flush()` for cold-path FIFO emission to streams with dropped-record overflow diagnostics.
  - Ergonomic logging macros (`ENG_LOG`, `ENG_LOG_INFO`, `ENG_LOG_WARN`, `ENG_LOG_FORMAT`, etc.) bound to `Logger::defaultLogger()`.
  - Comprehensive unit test suite in `tests/unit/core/log_test.cpp`.
- **Core Clock & Time Subsystem (Phase 1.3)**:
  - `Duration` in `<core/time/duration.h>` providing nanosecond-precision, integer-based time duration representation with unit conversions, overflow bounds, and arithmetic.
  - `Timestamp` in `<core/time/timestamp.h>` providing monotonic point-in-time representation backed by `std::chrono::steady_clock` with duration arithmetic.
  - `Clock` in `<core/time/clock.h>` providing independent timekeeper instances with real vs. scaled delta tracking, pause/resume, and negative scale protection.
  - `Budget` in `<core/time/budget.h>` providing execution-time quota tracking with microsecond accounting for standby mode preparation and incremental tasks.
  - Master include header `<core/time.h>`.
  - Comprehensive unit test suite in `tests/unit/core/time_test.cpp`.
- **Fixed-Size Pool Allocator & Generational Handles (Phase 1.2)**:
  - `PoolAllocator` in `<core/pool_allocator.h>` providing fixed-size, O(1) allocation and deallocation over caller-provided backing memory with intrusive free-list storage, configurable alignment, and double-deallocation rejection.
  - `GenerationalHandle` in `<core/generational_handle.h>` providing a lightweight 64-bit handle primitive (32-bit index + 32-bit generation) with explicit invalid sentinels, validity checks, and bit packing.
  - Comprehensive unit test suites in `tests/unit/core/pool_allocator_test.cpp` and `tests/unit/core/generational_handle_test.cpp`.
- **Core Memory Allocators (Phase 1.1)**:
  - Alignment utilities in `<core/align.h>` (`isPowerOfTwo`, `alignUp`, `isAligned`).
  - `LinearAllocator` in `<core/linear_allocator.h>` providing alignment-aware bump allocation over caller-provided memory with overflow safety.
  - `ArenaAllocator` in `<core/arena_allocator.h>` providing grouped memory management with scoped checkpoint rollback (`save()`, `restore()`) and bulk reset.
  - Comprehensive unit test suites in `tests/unit/core/linear_allocator_test.cpp` and `tests/unit/core/arena_allocator_test.cpp`.
- **Core Error Handling & Assertions (Phase 1.0)**:
  - `ENG_ASSERT` and `ENG_VERIFY` diagnostic assertion macros in `<core/assert.h>`.
  - Allocation-free `Error` and `ErrorCode` types in `<core/error.h>` with source location diagnostics.
  - Exception-free `Result<T, E>` and `Result<void, E>` in `<core/result.h>` supporting move-only types.
  - `hikari::engine_core` module target exporting `engine/core/include`.
  - Comprehensive unit test suite in `tests/unit/core/` covering success, failure, move-semantics, and assertion behaviors.
